# FoodScan Website (Next.js)

Phase 2 public **marketing** website. Not a calorie-tracking dashboard.

## Requirements

- Node.js 20+ (LTS recommended)
- npm

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

- `/` Home
- `/how-it-works`
- `/features`
- `/pricing` (placeholder, no payments)
- `/about`
- `/contact` (mock submit success)
- `/privacy` (placeholder)
- `/terms` (placeholder)

## Notes

- Tracking product lives in `ui_screens/mobile` (Flutter).
- No scan/meal/auth API wiring in this site for MVP.
